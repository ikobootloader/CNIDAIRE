# Cnidaire 2D

Simulation Python/Pygame d'un cnidaire en 2D avec environnement aquatique, interactions multi-organismes, proies, boucle principale de simulation, repères visuels de mouvement, pulsation de nage lisible et orientation dirigée vers les proies.

## Lancement

```powershell
python -m src.main
```

## Vérification

```powershell
python -m pytest -q
```

Le projet est actuellement validé par les tests d'organisme et d'orchestration.
